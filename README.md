Smart Parking IoT - Sistema de Control y Monitoreo de EstacionamientoSmart Parking IoT es una solución móvil e IoT desarrollada para Android (Kotlin) diseñada para gestionar, monitorear y controlar en tiempo real el acceso a estacionamientos inteligentes. El sistema interactúa mediante comandos Bluetooth RFCOMM con hardware embebido (Arduino UNO + módulo HC-05) y permite la sincronización de estado en tiempo real entre múltiples dispositivos Android mediante sockets TCP por Wi-Fi local.📐 1. Capa Hardware / OT (Arduino UNO + Módulo HC-05):Recibe y ejecuta instrucciones mediante protocolo serial por Bluetooth.Trama de Comandos Estándar:A: Abrir barrera de acceso.O: Cerrar barrera de acceso.E: Incrementar contador de vehículos (Entrada).U: Decrementar contador de vehículos (Salida).I: Reiniciar contador de capacidad.Capa Móvil (Android - Kotlin):Arquitectura UI/Data: Basada en patrón de estado reactivo (ParkingState), ViewBinding y manejo asíncrono con corrutinas/hilos.Módulos:ui.login: Control de acceso autenticado.ui.dashboard: Panel de monitoreo de métricas, cupos y sincronización Wi-Fi.ui.control: Interfaz remota de comandos de control manual por Bluetooth.ui.emergency: Módulo de contingencia con política Fail-Secure.Capa de Sincronización Multi-dispositivo (Wi-Fi P2P):WifiSyncManager implementa un servidor/cliente TCP en segundo plano (puerto 5055) que sincroniza la capacidad, ocupación y estados de emergencia entre dos teléfonos conectados a la misma red local o zona de cobertura Wi-Fi.📑 2. Descripción de Casos de Uso ClaveCU01 - Autenticación Segura: El usuario debe ingresar credenciales válidas. Las contraseñas se verifican utilizando hashing SHA-256 mediante AuthManager.CU03 - Control Manual: Envío de comandos directos (A, O, E, U, I) al microcontrolador previa validación de permisos runtime de Bluetooth (BLUETOOTH_CONNECT).CU05 - Gestión de Emergencia: Aplicación inmediata de protocolos de seguridad Fail-Secure en la barrera.👤 3. Ciberseguridad OT e ISO 27400 (Seguridad en IoT)El proyecto adopta lineamientos del estándar ISO/IEC 27400 (Cybersecurity for IoT) y principios de seguridad en entornos OT (Operational Technology):Autenticación y Control de Acceso (RBAC):Almacenamiento seguro de hashes en lugar de contraseñas en texto plano (MessageDigest.getInstance("SHA-256")).Control estricto de vistas: ninguna pantalla operativa es accesible sin pasar por el filtro de autenticación de LoginActivity.Seguridad en la Red Local (Segmentación Wi-Fi):El socket TCP opera estrictamente en rango LAN local, previniendo la exposición no deseada de servicios hacia redes públicas o Internet.Manejo Seguro de Permisos Android (Android 12+ / API 31+):Solicitud explícita de permisos BLUETOOTH_CONNECT en tiempo de ejecución, previniendo excepciones de seguridad (SecurityException) y garantizando el consentimiento explícito del usuario.🛡️ 5. Comportamiento Fail-Secure (Seguridad Ante Fallas)En sistemas de control de acceso e infraestructura crítica, el criterio Fail-Secure establece que ante un fallo de energía, desconexión de red o estado de pánico, el elemento de bloqueo debe permanecer CERRADO Y BLOQUEADO para evitar accesos no autorizados.Implementación en el Proyecto:Al ingresar a EmergencyModeActivity o detectar desconexión con el módulo HC-05, el sistema envía automáticamente el comando O (Cerrar Barrera).Si se interrumpe la comunicación Bluetooth, la barrera no queda flotante ni abierta por defecto, asegurando la contención del estacionamiento.🛠️ 6.
